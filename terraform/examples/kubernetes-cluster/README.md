# kubernetes-cluster example

This folder is the reference location for the generated **azurerm_kubernetes_cluster** workload.

The deployable composition is at the `terraform/` root and reusable implementation is under `terraform/modules/`.
Keep future scenario-specific examples here with their own `main.tf`, `variables.tf`, `outputs.tf`, and README.
Examples must contain placeholders only and must never include state, plan files, credentials, passwords, access keys,
SAS tokens, or private keys.
